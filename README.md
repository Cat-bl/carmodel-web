# BYD 车模编辑器

这是一个用于制作 BYD 车道级地图自定义车模的网页工具。

你可以导入自己的 GLB 车模，调整车头方向和尺寸，为车灯、车轮、车门等部件绑定联动效果，然后生成可以导入车机地图的 `.bydcar` 车模包。

## 能做什么

- 导入 GLB 车模并在 3D 视图中检查模型。
- 自动判断模型正面，并将车头对齐到车机方向。
- 手动调整旋转角度、车身长度和离地高度。
- 绑定近光灯、远光灯、刹车灯、日行灯。
- 绑定左转向灯、右转向灯和双闪，并预览闪烁效果。
- 绑定前轮、后轮的旋转效果。
- 绑定四个车门、引擎盖和后备箱的开合效果。
- 根据模型轮廓自动生成车底阴影。
- 通过“网页质感”和“车机质感”检查最终效果。
- 生成可供车机地图导入的 `.bydcar` 文件。

所有模型处理都在浏览器本地完成，模型文件不会因为使用本工具而上传到服务器。

## 使用流程

### 1. 导入模型

点击“导入 GLB 车模”，选择一个 `.glb` 文件。

建议：

- 文件大小不超过 32 MB。
- 模型最好已经包含贴图，并且贴图嵌入在 GLB 内部。
- 如果模型本身没有拆分部件，也可以在后面的“精细选面”中处理。

导入后，页面会显示模型大小、三角形数量、节点、网格、材质和贴图数量，并自动进行兼容性检查。

### 2. 调整车头方向和尺寸

画布中的蓝色箭头表示车机认定的车头方向。

通常自动识别结果可以直接使用。如果车头方向不对，可以使用：

- “左转 90°”
- “右转 90°”
- “反向”
- X、Y、Z 旋转输入框

还可以设置车身最长边和离地高度。调整后建议切换到“车机质感”再次确认。

### 3. 绑定联动部件

在左侧选择一个联动槽位，例如“刹车灯”或“前轮（左右一对）”。右侧会出现部件选择工具。

#### 整部件

适合模型已经拆分好部件的情况。

勾选一个部件即可绑定。多选时可以继续勾选其他部件，它们会一起加入当前槽位。

例如前轮通常应把左右两个轮子加入同一个“前轮（左右一对）”槽位。

#### 精细选面

适合车灯、轮胎和车身共用一个模型块的情况。

可使用：

- “智能点选”：点击模型表面，自动扩展到相邻曲面。
- “画笔”：在模型表面涂选区域。
- “添加”：把新区域加入当前选区。
- “减去”：从当前选区移除误选区域。
- “仅可见面”：避免从正面操作时穿透选到背面。

可以旋转模型后继续补选另一侧。同一个槽位可以包含多个不连续区域，因此左右两个轮子可以放进同一个槽位。

选择车轮后，页面会显示旋转中心。可以使用自动拟合，也可以手动调整旋转中心。

#### 旧框选

“旧框选”主要用于兼容旧配置和删除多余区域。对于车灯、车轮等需要精确绑定的部件，优先使用“整部件”或“精细选面”。

### 4. 预览效果

绑定完成后，可以直接在当前槽位中预览，也可以点击“全部演示”依次检查所有联动。

建议分别检查：

- “网页质感”：用于编辑和选择区域。
- “车机质感”：使用最终导出模型进行预览，更接近导入地图后的实际效果。

如果车机质感中的灯光、闪烁、车轮或开合效果不正确，应在生成前返回对应槽位调整。

### 5. 检查并生成

点击顶部“检查”，确认没有红色错误项。

然后点击“生成车模包”。浏览器会下载一个与模型同名的 `.bydcar` 文件，例如：

```text
2023_byd_han_dm-p.bydcar
```

生成过程中不要重复点击按钮，也不要关闭页面。

## 导入车机地图

1. 将生成的 `.bydcar` 文件复制到车机的 `Download` 文件夹。
2. 打开地图设置中的“导航设置”。
3. 进入“车道级车模”，选择“自定义”或导入车模包。
4. 在文件选择器中选中 `.bydcar` 文件。
5. 等待提示导入成功。
6. 完全退出并重启地图进程，再进入车道级地图查看效果。

## 常见问题

### 导入后没有变化

车机地图会缓存车模和贴图。导入成功后必须重启地图进程；只退出当前导航页面通常不够。

### 车机里看起来比网页暗

请先切换到“车机质感”检查。车机质感会使用最终导出模型和车机兼容材质进行预览，比“网页质感”更接近地图实际效果。

### 一个灯亮时其他灯也亮了

通常是多个灯绑定了同一片模型区域。回到对应灯光槽位，使用“精细选面”分别选择区域，避免把车身或其他灯一起绑定。

### 车轮转动时发生偏摆

打开车轮槽位，重新自动拟合旋转中心，或手动把旋转中心放到轮轴中心。左右轮应放到同一个车轮槽位中。

### 模型导入后很卡

模型三角形过多会增加车机实时渲染压力。生成时工具会尝试按车机预算减面，但复杂模型仍可能较慢。建议优先减少不可见内饰、底盘和重复细节，并控制贴图尺寸。

### 生成按钮不可用

先点击“检查”，处理红色错误项。常见原因包括材质数量过多、模型结构不符合车机限制或贴图过大。

## 本地启动

如果需要在电脑上运行网页：

```bash
npm install
npm run dev
```
